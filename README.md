# LGT-S1 校园/园区多媒体信息终端

基于安路 EG4S20BG256（HX4S20C 开发板）的纯 Verilog HDMI 数字标牌。无操作系统、无 MCU、无软核：TF 卡 FAT32 解析、BMP 解码与多尺寸重采样、SDRAM 四帧缓存、HDMI 1.4b 视频/48 kHz 音频、OSD 多图层、按键交互、参数掉电保存与播放事件日志全部在 FPGA 内完成。

> 一句话：**一块板 + 一张卡**，上电即播；内容进卡、设备自持、播放可核。

## 交付内容

| 路径 | 内容 |
|---|---|
| `firmware/LGT-S1-seed23-8210CF6A.bit` | 最终比特流（seed 23，MD5 `8210CF6AFE574C36B280B5A6C7AFF3A0`） |
| `TF_CARD/` | TF 卡根目录内容：4 张 BMP + 3 段 WAV + `PLAYLIST.TXT` + `MANIFEST.TXT` |
| `td_project/` | Anlogic TD 6.2.1 工程（`HDMI1.4b_Transmitter_v1.0.al`） |
| `user_source/` | RTL、约束、IP |
| `sim/` | 70 个 testbench 与仿真脚本 |
| `scripts/` | 构建、烧录、内容打包、串口监视、报告图生成 |
| `docs/LGT-S1-作品报告.pdf` | 设计报告（29 页） |

## 快速复现（评委/验收）

1. **准备 TF 卡**：FAT32 格式，建议 8 GB 以上。把 `TF_CARD/` 里的**所有文件复制到卡根目录**（不要套一层 `TF_CARD` 文件夹）。
2. **烧录比特流**：把 `firmware/LGT-S1-seed23-8210CF6A.bit` 烧到 HX4S20C（TD Download，或 `scripts/flash.sh`）。
3. **连接显示**：HDMI 接显示器/电视（需支持 640×480@60 与 HDMI 音频）。
4. **插卡上电**：设备自动挂载卡、扫描根目录、显示首图，按 `PLAYLIST.TXT` 轮播。
5. **异常恢复**：无卡/坏卡显示品牌封面或引导页；插回卡自动恢复；坏图重试一次后跳过；拔卡保留最后完整画面。

> 如果只看到品牌封面或“NO CONTENT / PUT BMP ON TF CARD”，优先检查：卡是否为 FAT32、文件是否在卡根目录、`PLAYLIST.TXT` 是否在根目录、BMP 是否为 24 位未压缩。

## TF 卡内容

| 文件 | 说明 |
|---|---|
| `01_campus_daily_640x480.bmp` | 日常发布 640×480 |
| `02_emergency_warning_640x480.bmp` | 应急预警 640×480（S14 直选） |
| `03_exhibition_1280x960.bmp` | 互动展陈 1280×960（2×2 均值缩放） |
| `04_evacuation_1024x768.bmp` | 疏散路线 1024×768（8:5 相位抽取，S16 直选） |
| `01_campus_daily.wav` | 日常背景音乐 48 kHz/16 bit 立体声，12.00 s |
| `02_exhibition_bgm.wav` | 展陈背景音乐 48 kHz/16 bit 立体声，12.00 s |
| `03_emergency_alert.wav` | 应急语音 48 kHz/16 bit 立体声，6.07 s |
| `PLAYLIST.TXT` | 4 条节目：日常/互动/应急/运维，图片只引用 1/3 |
| `MANIFEST.TXT` | 文件 SHA-256 清单；固件忽略该文件 |

`PLAYLIST.TXT` 每行格式：`序号, 秒数, 转场, 中文|ENGLISH`。序号从 1 起，对应扫描到的 BMP 顺序；秒数 0 表示跟随音频节拍，留空默认 8 秒；转场支持 `淡入/左揭示/右揭示/菱形溶解` 或数字 0–3；每种语言最多 39 字；`#` 开头与空行忽略。

## 操作

| 控件 | 功能 |
|---|---|
| KEY1 短按 | 单图 ↔ 四宫格 |
| KEY1 长按 | 切下一段 WAV，并联动显示图 1/3/2；第 3 首进入应急模式，锁住自动/节拍切图 |
| KEY2 / KEY4 | 正常播放：下一张 / 上一张（节目单历史）；编辑档：加/减一档 |
| KEY3 短按 | 编辑链：正常 → 亮度 → 对比度 → 特效 → 音效 → 正常 |
| KEY3 长按 | 进入/退出缩略图浏览 |
| SW1 | 拨上：整屏产品信息页（信息页内 KEY4 进 LOG、KEY2 返回） |
| SW2 | 拨上：常显状态栏 |
| SW3 | 拨上：自动轮播；拨下：手动 |
| SW4 | 拨上：演示模式（临时调节不保存） |
| S1–S4 | 音量 0/35/70/100% |
| S5–S8 | 字幕 0/35/70/100% |
| S9–S12 | 淡入 / 左揭示 / 右揭示 / 菱形溶解 |
| S13–S16 | 直选图 1/2/3/4 |

串口：USB1 CH340，FPGA 只从 TXD（D12）发送，115200 8N1，每约 1 秒一行 190 字节状态；可用 `scripts/uart_status_monitor.py COMx` 只读查看。

## 构建与仿真

- 工具：Anlogic TD 6.2.1 + ModelSim。
- 构建（Windows PowerShell）：`scripts/td_build.ps1 -Out <输出目录> -Seed 23`
- 构建（Linux/Git Bash）：`scripts/td_build.sh <输出目录> 23`
- 仿真：`sim/run.sh`（或 `sim/run.ps1`），共 70 个 testbench。
- 布局种子：23（SD/视频/存储三个功能域建立余量为正）。

资源与时序（最终 seed 23 构建）：

| 项目 | 结果 |
|---|---|
| LUT | 17,490 / 19,600（89.23%） |
| 寄存器 | 10,626（54.21%） |
| BRAM / DSP | 46/64 / 10/29 |
| 功能域建立 | SD +2.582 ns、视频 +8.150 ns、存储 +0.140 ns，0 违例 |
| 已知项 | 全局 setup WNS −6.565 ns（64 端点，SDRAM dq 路径）；hold −0.068 ns（15 端点） |

> 说明：上表“功能域建立 0 违例”指 SD/视频/存储三个功能域的内部时序；全局 SDRAM 引脚路径的已知负余量如实列在“已知项”，不宣称“全局零违例”。

## 设计要点

- **音画同频**：切图由 WAV 实际播放样本数驱动；误差在 HDMI IP 输入端测量并显示在状态栏 `AV xx.x MS`；波形/四频段柱/16 颗双色 LED 与音频同源。
- **四帧常驻**：BUF0–BUF3 各存一张 640×480 帧，首轮从卡读入；第二轮起切图不读卡；帧边界提交，切换无撕裂。
- **单卡可运营**：FAT32 + 节目单 + 双语字幕 + 坏图/坏节目单/拔卡降级 + 16 槽事件日志 + 屏上 LOG + 只读串口状态。
- **纯 Verilog**：无 OS/MCU/软核；所有算法与控制逻辑在 FPGA 内自主实现。

## 已知限制

- 参数单槽记录在擦写过程中断电可能失效并回默认值；正常断电重启可恢复。
- 未自制 PCB/外壳，使用 HX4S20C 开发板 + 亚克力立牌 + 黑色泡棉板展示。
- 串口只发不收；RXD 不接入逻辑。
- 全局 SDRAM 引脚路径存在已知负余量（见上表），不影响功能域时序与演示。
