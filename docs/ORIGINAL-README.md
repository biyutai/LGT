# LGT 音画同频数字标牌（LGT-S1）

> 作品：LGT 音画同频数字标牌 · 型号 LGT-S1 · 固件 1.0.0
> 第九届（2026）嵌入式大赛 FPGA 赛道 · 安路选题一
> 器件 EG4S20BG256 · 开发板 HX4S20C · 工具 TD 6.2.1

## 当前作品简介

本作品面向**门店橱窗、商业展陈、校园公告与应急信息发布**，是一台“一块板 + 一张卡”的 HDMI 数字标牌播放终端：把内容放进 TF 卡即可播放，断电自动恢复，坏内容自动跳过，无内容有引导页，播放过程可在板上 LOG 页查看，串口只输出只读状态。所有解析、缓存、音画同步、OSD 合成与故障恢复逻辑都用纯 Verilog 在 EG4S20 FPGA 内完成，不依赖 MCU、软核或网络。

系统支持最多 16 条节目单、4 张常驻 BMP 图片（640×480 / 1280×960 2×2 均值 / 1024×768 8:5 相位抽取 / 小图放大）、一段 48 kHz WAV、音频节拍切图、四种转场、6 档画面特效、5 段音频均衡、实时 OSD 调参与音频可视化；W25Q64 维护 16 槽环形播放事件日志。串口只从 FPGA TXD 单向输出状态，**不接收命令、不与其它外设联动**；本设计不使用数码管和蜂鸣器。

本仓库放**代码、运营手册与交付草稿**。赛题原文、官方模板与规划纪要另在 `../../anlogic-fpga-contest/`（`D:/MCU/FPGA/Anlogic/anlogic-fpga-contest`）。

## 板上操作

- HDMI 线接 **HDMI_B** 口
- TF 卡（FAT32，最多 4 张 BMP）先插好再上电。BMP 支持 320×180 非等比拉伸铺满、320×240 最近邻放大 2 倍、640×480 原尺寸、1280×960 走 **2×2 均值**降到 640×480（比最近邻平滑、无摩尔纹）、1024×768 走 **8:5 相位抽取**降到 640×480，五种尺寸可混放；均须为 24 位未压缩、正高度（BMP 底行先存储）。其它尺寸不会被扫描为图片。演示素材可用 `python scripts/make_large_bmp.py [--size 320x180] 输入图片 输出.bmp` 生成。
- 背景音乐：最多四段 48kHz / 16 位 / 立体声 WAV，KEY1 长按切下一首；没有 WAV 时当前版静音。短 WAV 可让四张图片常驻 SDRAM，长 WAV 使用双缓冲。
- FAT32 模式按根目录的短文件名目录项顺序读取前 4 张 BMP 和第一段 WAV，支持文件簇不连续及分区从 64MB 以后开始。请把演示文件直接放在卡根目录；普通复制即可，无须保证物理连续或固定复制顺序。支持 MBR FAT32 分区（类型 0B/0C）和无分区 FAT32，扇区须为 512 字节、每簇 1~128 扇区。未识别 FAT32 时仍按旧版前 64MB 原始扇区方式扫描。
- 可用 `python scripts/check_tf_image.py 整卡.img 图片1.bmp ... 音乐.wav` 按 FAT32 簇链检查实际卡镜像和源文件；单卡产品版要求 FAT32，不启用旧原始扇区回退。上板前先核对脚本显示 `VERIFY PASS`。
- 当前音频输入为 TF 卡 WAV，未插入 WAV 时回退到片内测试音。HX4S20C 开发板没有引出 EG4S20 的 ADC 模拟专用口，因此当前版本不宣称外部 ADC 实时音频采集；后续若取得芯片 ADC 专用映射，可沿现有 PCM 接口扩展。
- 上电后视频时钟就绪即显示片内 `LGT` 启动画面；找到第一张 BMP 后先载入并在帧边界切到照片，同时后台继续扫描其余图片和 WAV。扫描结束后载入 WAV；FAT32 模式按根目录顺序访问文件。四图常驻模式的第一轮仍需逐张从 TF 卡读入；从第二轮起可直接切换已缓存的图片。显示器本身的 HDMI 锁定时间不由 FPGA 控制。
- 四种转场由矩阵键选择：**S9 淡入、S10 左揭示、S11 右揭示、S12 菱形溶解**；选择后持续生效并可掉电恢复。KEY1 短按切四宫格、长按约 0.8 秒切下一首背景音乐；KEY2/KEY4 是下一张/上一张，SW3 控制自动轮播。有 WAV 时自动和演示切图均跟随音频节拍。
- **KEY1 短按切换"单图 / 四宫格拼贴墙"显示模式**：拼贴墙把扫描时缓存的四张预览图铺成 2×2 墙面（每格 320×240），每帧只读 153,600 字，SDRAM 读带宽从约 74MB/s 降到 37MB/s；此时按 S13~S16 仍可换"当前图"，顶部状态栏的图片序号跟着变，回到单图再按一次 KEY1。拼贴墙复用缩略图浏览的预览缓存与解包通路，不额外占帧缓存。
- 缩略图浏览模式：KEY3 长按（约 1 秒）进入，再长按一次或长按 KEY1 退出。进入后 KEY2 移动焦点框；**短按 KEY1 选中焦点图并自动进入该图**；**长按 KEY1（约 0.8 秒）只退出缩略图**，不改变当前显示图片、也不切换显示缓冲。浏览模式下长按 KEY1 不会误切下一首背景音乐。
- 顶部状态栏第 4 行交替显示两块内容，每 4 秒换一次：**运行时间戳** `运行 HH:MM:SS`（从 上电起算、99 小时循环，每秒刷新）和**系统自检行** `自检 V A S 帧 PP 读图 PP 秒 缓存 PP 欠载 PP`。时间戳是官方扩展要求(1)里点名的"动态文字（如时间戳或标语）"，板卡没有 RTC，所以显示运行时长而不是墙上时钟；自检行的 V/A/S 是视频/音频/存储健康标志的反（1 = 正常），帧 = 每秒帧数，读图 = 最近一次图片加载秒数，缓存 = 常驻缓存命中次数，欠载 = 音频 FIFO 取空次数（8 位饱和）。串口里原本要看的 PIC/ERR/BEAT/LD/HIT/TIME 这些状态，现在屏幕上直接有对照，现场演示不需要接串口。
- **控制面一览**（引脚出自《HX4S20 开发板手册-HDL 版 2410》：SW1~SW4 = C8/C7/C6/C5，拨上为 1；KEY1~KEY4 = A2/B2/B1/C1，按下为低）：
  拨码按"拨下 = 默认状态，拨上 = 特殊模式"统一；按键按"短按 = 常用动作，长按 = 次级动作"分层。

  **产品化呈现**：**SW1（C8）= 拨上翻开亮色产品信息页**，拨下收起；**SW2 拨上常显顶部状态栏**。状态栏“分辨率”显示真实 BMP 源尺寸，HDMI 输出固定为 640×480@60。演示卡四条节目都提供中英文双行字幕，S5 隐藏、S6/S7/S8 分别为 50/75/100% 字形清晰度。右上角旧节目角标和照片中部三秒黑色提示条已删除；开机与 1 分钟屏保使用亮色品牌封面，屏保不会显示读卡中的文案。串口每秒输出完整英文状态字段和文字加载阶段。

  | 开关 | 引脚 | 拨下（默认） | 拨上 |
  |---|---|---|---|
  | SW2 | C7 | 隐藏顶部状态栏 | 常显状态栏 |
  | SW3 | C6 | 手动播放 | 自动轮播 |
  | SW4 | C5 | 正常播放 | 自动演示模式 |

  | 按键 | 引脚 | 短按 | 长按（约 0.8~1 秒） |
  |---|---|---|---|
  | KEY1 | A2 | 单图 ↔ 四宫格；缩略图浏览中：选中焦点图 | 下一首背景音乐；浏览中：退出浏览 |
  | KEY2 | B2 | 下一张图；编辑链中：加一档 | — |
  | KEY3 | B1 | 编辑链前进 正常→亮度→对比度→特效→音效→正常；浏览中：退出浏览 | 进入/退出缩略图浏览 |
  | KEY4 | C1 | 上一张图；编辑链中：减一档 | — |

  矩阵键盘 16 键全部用于直选：S1~S4 音量 0/35/70/100%，S5~S8 字幕混合 0/35/70/100%，S9~S12 四种转场，S13~S16 第 1~4 张图片。
  板上 SW5（蜂鸣器使能）、SW6（双色 LED / 数码管选择）是硬件开关，FPGA 读不到。**本设计不使用数码管与蜂鸣器**：数码管扫描/译码逻辑与其约束已删除，原共享引脚只输出双色 LED 信号（SW6 需拨到 LED 物理档）；SW1（C8）接的是整屏产品信息页。
- 矩阵键盘 S1~S16：S1/S2/S3/S4 = 音量 0/35/70/100%，S5/S6/S7/S8 = 底部字幕混合 0/35/70/100%，S9~S12 = 四种转场，**S13/S14/S15/S16 = 直接跳到第 1/2/3/4 张图片**（不用等轮播，也不受当前播放模式限制；序号超出实际图片数或那张图损坏时忽略）。缩略图浏览模式下 S9~S16 都不生效，先退出浏览再按。
- 顶部“显示”会按当前图源显示原样、放大、缩小或拉伸；320×180 在水平方向放大 2 倍、垂直方向交替重复 2/3/3 行，铺满 640×480。尺寸与显示方式跟随实际显示缓冲切换，预加载下一图时不会提前变更。
- KEY3 在“正常 → 亮度 → 对比度 → 画面特效 → 音效 → 正常”之间循环，编辑档中 KEY2/KEY4 加减。亮度、对比度为 0~4 档；画面特效为关闭、灰度、反色、棕褐、左右镜像、单像素边缘六档。WAV 播放时后台可预加载下一张；读卡期间保留完整旧图。SD SPI 速率由当前分频决定，首图请用 640×480；参数稳定后自动保存，断电演示先等待写入完成。
- **单卡产品版保存参数**：亮度、对比度、转场和音量停止调节约半秒后写入 W25Q64 `0x7FE000`；重启读回有效记录并恢复。事件日志仍位于 `0x700000` 起的独立扇区，共用唯一 SPI store。擦写中断电时单槽记录可能回默认值，实卡效果仍需验证。
- 音量默认 4 档。手动切图和自动卡点轮播都保持背景音乐连续，不随画面转场改变音量。
- 音频可视化：画面下方左侧显示 PCM 波形，右侧四柱 `LO/LM/HM/HI`，8 颗双色 LED 使用同一组频段峰值做 PWM/追光；
  5 段均衡与音量仍工作。演示请使用 `assets/scale_demo/05_demo_beat.wav`（12 秒内 24 次柔和低频鼓点）。
- 另有 4 颗独立绿色 LED（LED1~LED4）：当前容量发布版直接镜像低频段四颗主 LED 的亮度，作为第二组状态灯；呼吸灯模块 `auto_breathe_led.v` 保留在仓库，试点版可重新开启。
- 原先显示在数码管上的四个量（音画同步最大误差 / 健康标志 / 节拍计数 / SD 状态码）已随数码管一起从 RTL 移除；健康、节拍、SD 状态在状态栏与串口报文里都有。**音画同步最大误差已上屏**：状态栏第 4 行时间戳变体右侧空槽显示 `AV xx.x MS`（0.1ms 单位，如 `AV 08.4 MS`），与自检行每 4 秒交替。
- 健康标志 `0` = 复位以来一切正常；`1` 画面读空、`2` 声音读空、`4` SDRAM 音频读口异常、`8` SD 看门狗动作过或图片/WAV 重试失败，多个同时出现时相加
- USB1（板载 CH340 Type-C）仅从 FPGA TXD=D12 输出 115200 波特、8N1 状态。运行中每约一秒输出一行 190 字节可读状态 `UPTIME=... IMAGE=... HEALTH=x`（字段见《运营手册》第 7 节）；事件日志不上串口，只在屏上 LOG 页显示最近 7 条。`tb_uart_slim_reporter` 逐字节比对 190 字节状态行。可运行 `python scripts/uart_status_monitor.py COMx --save capture.txt` 只读查看（需要 `pyserial`，Ctrl+C 退出）。串口 RXD 不接入 FPGA 逻辑，输入任何字节都不会控制任何功能；串口不与按键、LED、Flash 或任何其它外设联动。
- SD 状态码正常为 `1`；`4` = 正在读图，`5` = 正在载入 WAV


## 数字标牌（节目单 / 自检页 / 双语字幕）—— 见两份专门文档

音频音效为 5 段一阶分频图形均衡（4 档预设，KEY3 编辑链现场切换）；IIR 版本 `audio_eq.v` 已实现并通过
±1dB 频响测试，但集成后 mslice 超限，未例化。
