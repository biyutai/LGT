### 0.1 一镜到底规则

- **不允许**：剪辑、跳切、补拍、预录插入、蒙太奇、加速/减速、分段拍摄。
- **允许**：后期字幕、配音、资源表/亮点角标叠加、同一广角画面的 PIP/局部放大（不切镜头）；这些不改变连续画面。
- **机位**：A 机**运动镜头**，三脚架 + 云台；可缓慢摇/推/拉/变焦，但不切、不出画；B/C 机只录备选，**不剪进主片**。
- **人员**：建议 2 人——1 人按键/操作，1 人管 A 机；单人拍摄时用固定机位或遥控，不要边按键边大幅移动相机。
- **失败处理**：任何按键不响应、读卡等待、黑屏、花屏、口播卡顿，**整条重拍**；一镜到底没有后期补救。
- **顺序**：正式拍摄必须按 0:00→3:00 顺序一次录完；排练可以分段，正式不能先拍后面再补开头。

## 1. 开拍前准备

### 1.1 版本锁定

1. 烧录 bit：`scripts/flash.sh <上面的 bit 路径>`，烧完断电重新上电。
2. 写卡：`scripts/write_card_v1.ps1 -Drive E -Source build\card_campus_v3d -Yes`（先备份，再 SHA-256 校验）。已有 V3c 卡也可只覆盖同名 `04_evacuation_1024x768.bmp`，再更新清单。
3. 记录：bit MD5、卡 MANIFEST 的 SHA-256、拍摄日期。
4. 如果当天重新编译，必须重新记录 MD5，不能沿用本手册的数字。

### 1.2 上电前开关

| 开关 | 位置 | 说明 |
|---|---|---|
| SW4 | **下** | 演示模式必须关闭；拨上会强制自动轮播并改参数 |
| SW1 | **下** | 信息页关闭；开场拍信息页时再拨上 |
| SW2 | **上** | 状态栏常显，便于拍亮度/音量/AV 误差；干净画面可拨下 |
| SW3 | **上** | 自动轮播；应急段再拨下 |

矩阵键盘必须接好（S1~S16）；只接板载 KEY1~KEY4 无法直选图 2/4。

### 1.3 卡内容与三段 WAV 设计

图片：

| 图号 | 文件 | 角色 | 直选键 | 进节目单 |
|---|---|---|---|---|
| 1 | `01_campus_daily_640x480.bmp` | 日常发布 | S13 | 是 |
| 2 | `02_emergency_warning_640x480.bmp` | 应急预警 | S14 | 否 |
| 3 | `03_exhibition_1280x960.bmp` | 互动展陈 | S15 | 是 |
| 4 | `04_evacuation_1024x768.bmp` | 疏散路线 | S16 | 否 |

三段 WAV 的设计与用法：

| 文件 | 角色 | 时长 | 设计要点 | 视频位置 |
|---|---|---|---|---|
| `01_campus_daily.wav` | 日常 BGM | 12.00s | 90 BPM；去掉强低频鼓点，保留很轻的 55 Hz 心跳；第 1/5/9 秒各一次柔和钟声；情绪“平稳、可长时间循环” | 基础 0:26–0:30；扩展 0:30–0:40；主题第一幕；恢复日常 |
| `02_exhibition_bgm.wav` | 展陈 BGM | 12.00s | 112 BPM；拨弦琶音 + 轻高频节拍 + 柔和低频脉冲；明显更明亮，适合展陈/参观 | 主题第二幕 1:14 切入 |
| `03_emergency_alert.wav` | 应急语音 | 6.07s | 中文 TTS：“请注意，这是消防演练，请沿安全通道有序撤离。”；无音乐、吐字清晰、留足尾音 | 主题第三幕；S14 预警后、S16 疏散前 |

设计逻辑（口播/报告可用）：

1. **三段音频对应三种状态**：日常要“不打扰”，所以 90 BPM、轻心跳、每 4 秒钟声；展陈要“更明亮”，所以 112 BPM、拨弦和高频轻打击；应急要“听得清”，所以直接用中文 TTS，不加音乐。
2. 三段都是 **48 kHz / 16 bit / 立体声标准 WAV**，44 字节头；首尾 20 ms 淡入淡出，循环接缝不“咔嗒”。
3. 三段都 ≤12 s；四帧常驻模式下音频区 714,752 字 ≈14.89 s，**单段**可整段放入；KEY1 长按切下一段时从卡上重新载入。
4. **KEY1 长按**循环 `01 → 02 → 03 → 01`；切换时要重新载入，短暂无声（约 1~2 秒，按卡速/文件大小）；一镜到底不能剪，用现场手部动作/口播填满，不要停录。
5. 当前容量版**没有 WAV 时静音**，不宣称片内测试音；视频里必须确保三段 WAV 都在卡上。

节目单：4 条模式（日常/互动/应急/运维），图片只引用 1/3；图 2/4 不进日常轮播。

### 1.4 预热门（每次开拍前）

1. **门店重启预演**：先热机 20~30 秒让四图/WAV 就绪，再断电 3 秒做重启镜头；拍一次“插卡→电源插排→品牌封面→自检→首图”，确认全过程无黑屏等待、无调试画面。若冷启动超过 10 秒，改用 RESET/PROGRAM 热复位，或整条重拍；一镜到底不能跳切。
2. 等 20~30 秒，让四图缓存和三段 WAV 就绪；状态栏应显示“自动”。
3. 依次按 S13/S14/S15/S16 各一次，确认图号映射和四张图都能出；最后按 S13 回日常。
4. 试一次 KEY1 长按：`01 → 02 → 03 → 01`，确认三段音频都能切；每次等约 1~2 秒，听清 03 的 TTS 内容。
5. 试一次 SW1 上/下：信息页进出，画面不切图。
6. 试一次 KEY3 长按：缩略图进出，确认后退出。
7. 用秒表走一遍 3:00 时间轴，确认五段卡点：0:10 / 0:30 / 1:00 / 2:30 / 3:00。

### 1.5 场景/机位/灯光/收音

- 三个区域：**门店/服务点**（收银台/服务台 + 电源插排 + “营业中”牌 + 终端 + 产品立牌）、**信息发布区**（显示器 + 开发板）、**值班台**（控制面板 + A4 通知 + 夹板/工牌/红夹）。
- 门店/服务点就是开场重启的场景；不需要真收银机，一张服务台、一个插排、一块“营业中”牌即可。
- 显示器中心离地 1.1~1.2m；开发板右侧支架；HDMI/电源线从后方走。
- 16:9 画面里屏幕是 4:3：两侧留侧栏放功能字幕/资源表，**不要压屏幕底部**（FPGA 双语字幕在 y=432~471）。
- 一镜到底只用 A 机**运动镜头**：三脚架 + 云台，可缓慢摇/推/拉/变焦，但不切、不出画；B/C 机只录备选，不剪进主片。
- 重启开场：先从电源插排/手部开始，镜头跟随手到屏幕，再拉宽到服务台+终端；可推/摇，但不能切。
- 屏幕需要看清楚时，镜头推近/变焦到屏幕；讲完再拉回全景；不要一直用远景硬撑。
- 屏幕尽量大（建议 ≥27 英寸）、高亮度、抗反光；相机用 4K 16:9 拍，后期导出 1080p，推近后屏幕字更清楚。
- 操作者站在画面侧边，不要挡住屏幕；按键前用指示笔/手指点一下，镜头可以跟到按键再拉回。
- 主光 45° 左、辅光 45° 右；不要直射屏幕；关顶灯；黑布遮线；“营业中”牌不要过曝。
- 配音：提前写稿，后期录；环境安静，手机/麦克风距离 20~30cm；语速平稳，重点处放慢。
- 设备声从显示器/音箱线路输出；配音为主，设备声压到 −12~−18 dB；基础段留 2 秒纯音乐。

### 2.4 关键前置条件

- **SW3 拨下后等约 1 秒**，看到状态栏“播放 手动”再按 S 键；否则挂起的音频节拍可能把画面切走。
- **手动模式 60 秒**无按键会回品牌屏保；应急段必须在 60 秒内完成，或中途按任意矩阵键/KEY1 短/KEY2/KEY4/KEY3 短复位计时。KEY1 长按不算复位。
- **KEY1 长按切 WAV**：短暂无声（约 1~2 秒，按卡速）是正常的；一镜到底不能剪，用现场手部动作/口播填满，不要停录。
- **KEY4 历史版**：KEY2/KEY4 都只在节目单图片（1/3）之间走；图 2/4 只能用 S14/S16 直选。
- **KEY3 短按**：<1 秒；按住 ≥1 秒会进缩略图，S13~S16 在浏览模式全部失效。
- **编辑链**：正常→亮度→对比度→特效→音效→正常；到“特效”要短按 3 次，到“音效”要 4 次。
- **参数保存**：调完亮度/对比度/转场/音量后等至少 2 秒再断电。
- **S9~S12**：选一次后，后续切图持续使用该转场（手动覆盖）；主题段若要回到节目单逐条转场，先断电重启。
- **SW1 信息页**：会屏蔽 KEY2/KEY4 的播放动作；KEY4 打开 LOG，KEY2 返回信息页；拨下 SW1 前先返回信息页，LOG 标志不会自动清零。

### 5.1 布局（一个连续镜头覆盖所有区域）

```text
┌──────────────────────────────────────────────────────────────┐
│  16:9 运动镜头（三脚架+云台，可摇/推/拉/变焦，不切）          │
│                                                              │
│  左侧前景                中间                    右侧         │
│  ┌──────────────┐   ┌──────────────────┐   ┌──────────────┐  │
│  │ 服务台/收银台 │   │ 4:3 显示器 640×480│   │ 开发板 + TF  │  │
│  │ 电源插排      │   │ 占画面高度 40~50% │   │ 矩阵键盘      │  │
│  │ “营业中”牌   │   │ 校园/园区信息发布 │   │ KEY1~KEY4     │  │
│  │ 产品立牌      │   └──────────────────┘   │ SW1~SW4       │  │
│  └──────────────┘    A4 通知/夹板/工牌      └──────────────┘  │
│                                                              │
│  侧栏（后期字幕/资源表）：功能名、关键参数，不压屏幕底部 OSD  │
└──────────────────────────────────────────────────────────────┘
```

> 关键：**电源插排和显示器在起始画面同框**；之后镜头可跟手、推近屏幕、再拉回全景，但不能切。控制面板/矩阵键盘放在显示器右下，手伸过去就能按。

### 5.2 道具

- 门店/服务点：服务台或收银台、电源插排、“营业中”牌、产品立牌 `LGT-S1 校园/园区多媒体信息终端`
- 按键贴纸：S1–S4 音量、S5–S8 字幕、S9–S12 转场、S13 日常、S14 预警、S15 展陈、S16 疏散；用大号高对比字，广角下才看得清
- 指示笔/教鞭：按键前点一下，观众知道按的是哪个键
- A4 `园区消防演练通知`、手机/对讲机
- 夹板 `日常巡检 / 应急发布 / 恢复确认`、工牌、红文件夹、展陈导览卡
- 黑色亚克力/泡棉板藏线；柔光补光灯；黑布；显示器尽量大（≥27 英寸）、亮度高、表面哑光

### 5.3 机位/灯光/收音（运动镜头版）

- **A 机运动镜头**：三脚架 + 云台，可缓慢摇/推/拉/变焦，但不切、不出画；B/C 机或采集卡只录备选，不剪进主片。
- **机位运动路线**（提前排练）：起点广角（电源插排+屏幕）→ 推近屏幕（名称/自检/首图）→ 拉宽到产品/开发板 → 摇到键盘/手部按键 → 推近屏幕（字幕/特效/轮播）→ 拉回产品全景。全程慢、稳，起停有缓冲，不快速甩镜。
- 相机用 **4K 16:9** 拍，后期导出 1080p；广角时屏幕占画面高度 40~50%，需要看字时推近/变焦，讲完再拉回。
- 如果没有 4K，用 1080p + 更大的显示器/更近的机位；推近后屏幕占画面高度 ≥50%，否则字幕承担屏幕细节。
- 手机拍摄：4K 16:9、三脚架/稳定器、手动对焦/锁定曝光、关闭自动亮度/防抖；缓慢移动，不要快速数码变焦。
- 相机与屏幕中心大致同高，尽量水平；推近手部时可以轻微下俯，但不要大角度俯拍/仰拍。
- 手动对焦：广角时对在显示器/键盘平面；推近屏幕后重新对焦；锁定曝光和白平衡；关闭自动对焦、防抖、自动亮度。
- 屏幕抗反光：关顶灯、避免窗户直射、镜头加遮光罩；显示器表面尽量哑光。
- 操作者穿深色纯色衣服，站画面侧边，不要挡住屏幕；按键前用指示笔点一下；镜头可以跟到按键再拉回，不切特写。
- 如果后期允许，可对**同一画面的屏幕/手部区域**做 PIP/放大角标（不切镜头）；如果完全不做后期放大，字幕必须承担屏幕内容，按键贴纸要大、用指示笔点按。
- 音频：相机离得远，不要依赖机头麦克风；用独立录音/后期配音，设备声从显示器/音箱线路输出，配音为主，设备声压到 −12~−18 dB。

### 5.4 排练顺序

1. 门店重启预演：断电/上电，确认封面→自检→首图干净。
2. 预热门（四图 + 三段 WAV + 缩略图 + 信息页）。
3. 基础 20 秒，每项 4 秒，一次成功。
4. 扩展 30 秒，按 `0:30–1:00` 顺序。
5. 主题四幕，按 `1:00–2:30` 顺序，计时 90 秒。
6. 结尾 30 秒，资源/可靠性/收尾。
7. 连续完整走 3 遍，再开始正式拍。

> 正式拍摄必须按 **0:00→3:00 顺序一次录完**；排练可以分段，正式不能先拍后面再补开头。
>
> 机位运动检查：起点广角（电源插排+屏幕）→推近屏幕→拉宽产品→摇到键盘→推近屏幕→拉回全景；每个停点屏幕字在监看器上可读；运动慢/稳；不切、不出画。

## 6. 失败恢复与重拍

| 现象 | 先检查 |
|---|---|
| 重启开场拍到等待/黑屏 | 一镜到底不能剪；整条重拍，或改用 RESET/PROGRAM 热复位 |
| S14/S16 无反应 | SW4 是否下、SW3 是否下、矩阵是否接、四图是否缓存、是否在缩略图/编辑档 |
| SW3 拨下后画面还是被切 | 等 1 秒再按 S 键；看状态栏“播放 手动” |
| KEY3 想调参却进了缩略图 | 按住超过 1 秒了；短按 <1 秒；退出用 KEY3 长按/KEY1 长按 |
| KEY1 长按没切歌 | 是否在缩略图浏览；长按是否 ≥0.8 秒；切歌短暂无声（约 1~2 秒） |
| 切 WAV 出现短暂无声 | 镜头保持，用现场手部动作/口播填满；不要停录 |
| LOG 页退不出去 | KEY2 返回信息页，再拨下 SW1 |
| 参数重启没恢复 | 调完是否等 2 秒；首次空 Flash 回默认值是正常的 |
| 手动模式 60 秒后回封面 | 按任意矩阵键/KEY1 短/KEY2/KEY4/KEY3 短复位；应急段控制在 60 秒内 |
| 画面/字幕与预期不符 | 先核对 bit MD5、卡 MANIFEST、S 键映射；不要现场调试，停拍重来 |

**重拍原则**：任何一次按键失败、读卡等待、黑屏、花屏，整条重拍；一镜到底没有后期补救。门店重启只录一次成功上电。
