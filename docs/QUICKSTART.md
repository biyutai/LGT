# LGT-S1 快速上手（一页纸）

## 你拿到的是什么

`LGT 音画同频数字标牌`（型号 `LGT-S1`，固件 `1.0.0`）是一台**插卡即播**的 HDMI
数字标牌：内容全部放在 TF 卡根目录，不需要装系统、不需要联网、不需要上位机。

需要的硬件：HX4S20C 开发板、5V USB 供电、支持 HDMI 音视频的显示器/电视、FAT32 TF 卡。

## 三步放内容

1. 先在电脑上备份唯一的 TF 卡，再确认它是 **FAT32**，容量建议 8GB~32GB。
2. 用 `python scripts/package_content.py assets/scale_demo --out build/card_demo` 打包内容；按 `MANIFEST.TXT` 顺序把四张 BMP、两段 WAV 和 `PLAYLIST.TXT` 复制到卡根目录，640×480 图先复制。
3. 保持 `PLAYLIST.TXT` 的 `序号, 秒数, 转场, 字幕` 格式；最多 16 条，秒数 `0` 表示跟随音频节拍。双语字幕用 `|` 分行。

要优先演示首轮切图速度，可改用 `build/card_fast_20261018` 中已经校验的四张 640×480 BMP、两段 WAV 和节目单；原 `assets/scale_demo` 保留 1280×960 与 1024×768 源图用于展示 FPGA 缩放。

改完先自检：

```bash
python scripts/check_playlist_font.py
python scripts/test_package_content.py
```

`package_content.py` 会校验 BMP/WAV/节目单、检查字幕缺字，生成可直接拷到卡根目录的
目录和带 SHA-256 的 `MANIFEST.TXT`；加 `--check-only` 只检查不复制。

## 上电看到什么

1. 无卡时保持中央 LGT 封面与“插卡即播”；插入 TF 卡且首图未就绪时显示 7 项开机自检。
2. 第一张图就绪后自动进片，按节目单轮播；底部可见中英两行字幕，右上角不再覆盖角标。
3. 调整亮度、对比度、转场或音量后保持约 2 秒，正常断电重启，设置应从 W25Q64 恢复。
4. 只有 SW3 拨下的手动模式才计屏保时间；连续 1 分钟无操作进入亮色封面。SW3 拨上立即退出并清零，重新拨下后从零开始计时；按键或换卡也会唤醒。

## 最常用的板载操作

| 操作 | 作用 |
|---|---|
| KEY1 短按 | 单图 ↔ 四宫格拼贴墙 |
| KEY1 长按 | 下一首背景音乐 |
| KEY2 短按 | 下一张图 / 编辑档加一档 |
| KEY4 短按 | 上一张图 / 编辑档减一档 |
| KEY3 短按 | 切换编辑档（亮度/对比度/特效/音效） |
| KEY3 长按 | 进入/退出缩略图浏览 |
| SW1 拨上 | 整屏产品信息页 |
| SW2 拨上 | 常显状态栏（默认拨下=干净画面） |
| SW3 拨上 | 自动轮播 |
| SW4 拨上 | 演示模式（临时参数不写 Flash） |
| S9–S12 | 选择并保持当前转场，直到再次手选或恢复出厂参数 |

首次空参数 Flash 使用默认 `2/2/淡入/4`；保存完成后重启恢复。`TEXT.TXT` 与非 FAT32 原始扇区回退不属于单卡产品版。

## 留一份“播放证明”

串口只读，不接任何控制：

```bash
python scripts/uart_status_monitor.py COM5 --save demo_capture.txt \
    --report-html demo_report.html
```

按 Ctrl+C 结束后生成报告，包含上电会话、每个条目停留秒数、换条次数与故障次数。
报告时间是“上电以来”的相对时间，不是墙钟时间。

## 常见问题

| 现象 | 先看这里 |
|---|---|
| 一直停在封面 | TF 卡是否 FAT32；根目录是否至少有一张受支持的 BMP |
| 字幕是空框 | 字库缺字；运行 `check_playlist_font.py`，按提示补字后重编译 |
| 自检页“节目单解析”红点 | 检查节目单字段/序号/转场；串口 `PLAYLIST_ERRORS` 是错误数，`LOAD_PHASE` 是加载阶段 |
| 没有声音 | 显示器/电视是否支持 HDMI 音频；WAV 是否为 48kHz 16bit 立体声 |
| 复位后停在第一张 | 看 SW1 信息页的“播放”字段；若显示“手动”，拨上 SW3 才会自动轮播。手动模式用 KEY2/KEY4 切图 |
| 切图很慢 | 首轮未缓存的 BMP 仍需从卡读取；按打包清单顺序复制，确保 640×480 图排在前面。产品 bit 的数据 SPI 为 12.5 MHz，需实卡验稳；首图后先加载 WAV，其余图片后台缓存 |
| 画面有撕裂/花屏 | 先录串口状态和 `HEALTH`，再检查 SDRAM 视频读空记录 |

完整语法、按键矩阵和已知限制见 [运营手册](signage-operator-guide.md)。
