## 0. 验证前准备

### 0.1 硬件

- HX4S20C 开发板，5V USB 供电。
- HDMI 线接 **HDMI_B**，显示器/电视要支持 HDMI 音频（或外接音箱）。
- FAT32 TF 卡，建议 8GB~32GB。
- USB1（CH340）接电脑，用于只读串口抓包；**串口不接收命令**。
- 如果要验证按键，准备杜邦线/矩阵键盘；矩阵键 S1~S16 需要接到板载矩阵接口。

### 0.2 一张“标准验证卡”

用仓库里的演示素材生成：

```bash
python scripts/package_content.py assets/scale_demo --out build/card_validation
```

先备份唯一的 TF 卡，再按生成的 `MANIFEST.TXT` 文件顺序复制到 FAT32 根目录。应包含：

- 4 张 BMP：1280×960、640×480、1024×768、640×480；
- 2 段 48kHz/16bit/立体声 WAV；
- `PLAYLIST.TXT`、`MANIFEST.TXT`。前者含双语字幕；`TEXT.TXT` 不进入单卡产品包。

坏 BMP、坏节目单、空卡、非 FAT32 格式由仿真验证，不在唯一的演示卡上破坏文件。

### 0.3 记录方式

每个阶段至少留一种证据：

- 手机拍照/录像（屏幕、LED、接线）；
- 串口抓包文件；
- 编译/仿真日志截图；
- 板上现象记录表（见文末模板）。

## 1. P0：上电与基础通路（5 分钟）

### 1.1 只上电、不插卡

| 步骤 | 预期 |
|---|---|
| USB 供电，HDMI 接显示器 | 显示器锁定 640×480@60，出现品牌封面 |
| 等待 2 秒 | 进入“无内容引导页”，不能黑屏 |
| 观察 4 颗绿色 LED | 有微弱/随音频变化的亮度；不要求呼吸 |
| 按任意键 | 画面应恢复/保持，不应死机 |

**通过标准**：有画面、无黑屏、无花屏；无卡时能进引导页。

### 1.2 插标准卡重新上电

| 步骤 | 预期 |
|---|---|
| 插卡、重新上电 | 品牌封面 → 开机自检页 → 第一张图 |
| 自检页 7 项 | TF 卡挂载、图片扫描、SDRAM 环回、音频通路、HDMI 锁定、存储自检、节目单解析；失败项是红点，但不阻塞播放 |
| 第一张图 | 640×480 或节目单指定的图，画面完整 |
| 底部字幕 | 中文 y=432–447、英文 y=456–471，横向可到 x=631；字间无整片底色 |
| 右上角 | 保持照片原样，不出现旧 `n/总 A/M` 角标 |

**通过标准**：首图出现，中英字幕可见，自检页不是全红。

### 1.2a RESET/PROGRAM 热复位

保持同一张 TF 卡插在板上且不断电，正常播放时按 RESET/PROGRAM。
自检页应显示彩色 `LGT` 和纵向分布的七项健康状态；`n/4` 位于“图片扫描”行，
不应出现在“TF 卡挂载”旁。首图随后重新出现。抓串口确认
`TF_CARD=READY`、`LOAD_PHASE=READY`、`IMAGE` 为有效编号；若持续
`SD_INIT` 且 `HEALTH=8`，记录该行、烧录 bit 的 MD5 和复位后的等待秒数。

### 1.3 HDMI 音频

| 步骤 | 预期 |
|---|---|
| 播放标准卡 | 能听到 WAV 音乐，不是蜂鸣器/方波 |
| 按矩阵 S1/S2/S3/S4 | 音量 0/35/70/100% 变化 |
| 观察 8 颗双色 LED | 随音乐频段闪动 |

**通过标准**：声音连续、无明显断续；音量键有效；LED 有律动。

## 2. P1：基础播放与交互（15 分钟）

### 2.1 手动切图

| 操作 | 预期 |
|---|---|
| KEY2 短按 | 下一张 |
| KEY4 短按 | 上一张 |
| S13/S14/S15/S16 | 直接跳到第 1/2/3/4 张 |
| KEY1 短按 | 单图 ↔ 四宫格拼贴墙 |

**通过标准**：每次切图画面完整，无撕裂；四宫格里 4 张预览都在。

### 2.2 自动播放

| 操作 | 预期 |
|---|---|
| SW3 拨上 | 自动轮播开启 |
| SW3 拨下 | 自动轮播关闭 |
| 有 WAV 时观察切图 | 切图跟着音频节拍/节目单秒数走 |

**通过标准**：自动/手动切换不黑屏，音乐不中断。自动冷启动时首图先显示，WAV 加载完成后开始播放，其余图片在后台常驻；缓存就绪后 1→2→3→4→1 每个节拍只切一张。缓存未完成时记录首轮读图等待时间；WAV 太长而不能四帧常驻时同样记录等待时间。

### 2.3 缩略图浏览

| 操作 | 预期 |
|---|---|
| KEY3 长按约 1 秒 | 进入缩略图浏览，出现焦点框 |
| KEY2 短按 | 移动焦点 |
| KEY1 短按 | 选中焦点图并进入 |
| KEY1 长按约 0.8 秒 | 只退出浏览，不改变当前图 |

**通过标准**：焦点移动正确，选图后进入对应图片，退出不误切音乐。

## 3. P2：五个扩展项逐项验（20 分钟）

### 3.1 图层叠加与字幕

1. 让标准卡播放；
2. 观察底部中英两行字幕、照片右上角、顶部状态栏；
3. 拨 SW2 上，状态栏常显；拨下，画面干净；
4. 按 S5 隐藏节目字幕，再按 S6/S7/S8 比较 50/75/100% 三档；
5. 四条节目均写 `中文|ENGLISH`，逐条确认上下双行。

**通过标准**：双语与状态栏清楚可读；右上角角标与中部黑色提示条均不出现。

### 3.2 轮播与转场

1. 依次按 S9/S10/S11/S12，各自再按 KEY2 切图；
2. 观察淡入、左揭示、右揭示、菱形溶解各生效一次；
3. 再切下一图，应继续保持刚手选的转场；重新按另一转场键后才改变。

**通过标准**：一张卡能看到四种转场；手选后连续切图效果保持一致，切换过程不黑屏。

### 3.3 图片缩放适配

标准卡的四张图分别覆盖：

| 文件 | 源尺寸 | 预期 |
|---|---|---|
| `01_landscape_1280x960.bmp` | 1280×960 | 2×2 均值降到 640×480，边缘应比最近邻平滑 |
| `02_forest_640x480.bmp` | 640×480 | 原样显示 |
| `03_strawberry_1024x768.bmp` | 1024×768 | 8:5 相位抽取到 640×480；能完整显示，不拉伸变形 |
| `04_apple_640x480.bmp` | 640×480 | 原样显示 |

**注意**：1024×768 只走 8:5 相位抽样，不做 2-tap 面积加权；
看到轻微锯齿是预期，不是坏图。

### 3.4 实时参数调节与 OSD

1. KEY3 短按循环：正常 → 亮度 → 对比度 → 特效 → 音效 → 正常；
2. 在亮度/对比度档，KEY2 加一档、KEY4 减一档；
3. 拨上 SW2，观察顶部状态栏数值；
4. 特效档依次看：关闭/灰度/反色/棕褐/左右镜像/边缘；
5. 音效档看低频/明亮/组合三种预设。

**通过标准**：画面即时变化；照片中部无旧黑色提示条；退出编辑后切图恢复。

**注意**：亮度、对比度、转场、音量稳定后写 W25Q64；特效档与音效档不保存。

### 3.5 音频可视化

1. 播放 `05_demo_beat.wav`；
2. 观察左下 PCM 波形、右侧四根频谱柱、8 颗主 LED；
3. 按 S1~S4 改音量，柱子和 LED 应跟着变；
4. 在音效档切换，频谱形态应变化。

**通过标准**：波形/柱子/LED 与音乐同步，不是固定动画。

## 4. P3：产品化与异常恢复（15 分钟）

### 4.1 自检页 / 信息页 / LOG 页

| 操作 | 预期 |
|---|---|
| 首图出现前看自检页 | 7 项逐项打勾/打叉 |
| SW1 拨上 | 整屏产品信息页：LGT-S1 / FW 1.0.0 / 图片/播放/亮度/对比度/字幕/尺寸/转场/音量/自检/运行时长 |
| SW1 上时按 KEY4 | 进入“播放记录”，显示最近 7 条中文事件、运行秒数和相关图号 |
| LOG 页按 KEY2 | 返回信息页 |

**通过标准**：信息页/播放记录能进能出；事件显示“设备启动/图片切换/读取失败/卡片移除”等中文名称，无事件时显示“暂无播放记录”。

### 4.2 坏图跳过（仿真）

运行 `powershell -File sim/run.ps1 tb_wav_load`，检查坏首图、截断图和重试后跳过用例均为 PASS。不要破坏唯一的演示卡。

### 4.3 拔卡 / 无卡

1. 播放中直接拔出 TF 卡；
2. 观察画面、LED、串口；
3. 重新插回同一张卡。

**通过标准**：画面不黑；无卡时保持中央大号 LGT 与完整的“插卡即播”，不覆盖自检表；插回后能恢复扫描/播放，并留下拔卡事件。

### 4.4 断电重启

1. 拔电 5 秒再上电；
2. 观察封面、自检、首图；
3. 调参后先等待至少 2 秒再断电；确认亮度/对比度/转场/音量从 W25Q64 恢复，旧 LOG 仍可查。

**通过标准**：每次自动启动，已成功保存的四项参数恢复。首次空参数 Flash 使用默认值；写入中断电可能因单槽校验失败回默认值，需另记为限制。

### 4.5 待机/屏保

1. SW3 拨上自动模式，连续 1 分钟不按键，确认不进屏保；
2. SW3 拨下手动模式，连续 1 分钟不操作，确认回到品牌封面；
3. SW3 拨上应立即退出屏保；再次拨下，等待不足 1 分钟时不得提前进入屏保；
4. 按任意键或换卡，也应立即恢复并重新计时。

**通过标准**：只在手动模式计时，离开手动模式清零。

### 4.6 节目单容错

1. 把某行转场改成 `XYZ`；
2. 重新上电；
3. 看自检页“节目单解析”/状态行 `E` 是否计数；
4. 确认播放不阻塞，未知转场回落淡入。

**通过标准**：错误可计数，画面继续播。

## 5. P4：屏上播放记录与串口状态（10 分钟）

### 5.1 屏上记录

开机自检页窗口内用 KEY2/KEY4 翻到“播放记录”。

**通过标准**：标题与时间/事件/图片三列可读；最近 7 条事件按时间倒序排列；无事件时显示“暂无播放记录”；第 8 行位置保持空白。使用带双语字幕的节目单进入播放记录页，分别开启、关闭字幕，确认第 7 条记录下方至底部色带均无多余字迹。

### 5.2 串口状态

```bash
python scripts/uart_status_monitor.py COM5 --save demo_capture.txt
```

操作：上电 → 手动切 2~3 张图 → 拔卡 → 插回 → Ctrl+C。

预期串口每秒出现：

```
UPTIME=01:02:03 IMAGE=2/4 AUTO_MODE=ON TF_CARD=READY WAV_AUDIO=READY BRIGHTNESS_LEVEL=2 CONTRAST_LEVEL=2 VOLUME_LEVEL=4 TRANSITION=FADE PLAYLIST_ERRORS=0 LOAD_PHASE=READY HEALTH=0
```

**通过标准**：

- `UPTIME` 每秒递增；
- `IMAGE`/`AUTO_MODE`/`TF_CARD`/`WAV_AUDIO`/`LOAD_PHASE` 与实际状态一致；
- 串口不出现 `L` 开头的事件行；
- 报告时间标注为“上电以来”，不是墙钟。

## 7. 失败时先看哪里

| 现象 | 优先检查 |
|---|---|
| 完全无 HDMI | HDMI 是否接 **HDMI_B**；供电；bit 是否烧成功 |
| 有画面无声音 | 显示器是否支持 HDMI 音频；WAV 是否 48kHz/16bit/立体声 |
| 字幕空框 | 运行 `check_playlist_font.py`，缺字要补字库并重编译 |
| 自检“节目单解析”红 | `PLAYLIST.TXT` 序号/转场/行数是否越界 |
| 一直停在封面 | 卡是否 FAT32；根目录是否有受支持 BMP |
| 切图慢 | 大图首次读卡受 SPI 速率限制；首图建议 640×480 |
| 花屏/黑屏 | 抓串口健康位；确认是否 SDRAM 读空/掉卡 |
| 参数重启没恢复 | 检查是否下载新 bit、是否调节后等待写入、参数记录是否校验有效 |
