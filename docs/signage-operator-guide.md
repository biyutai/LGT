# LGT 音画同频数字标牌 · 运营手册

这份文档面向"用这张卡放内容的人"，不是面向改 RTL 的人。运营改内容只动 TF 卡上的文本文件，
固件（比特流）不用重刷。

## 1. 产品是什么

一块 EG4S20 开发板 + 一张 TF 卡 + 一台 HDMI 显示器 = 一台**可运营的数字标牌**：
上电自检 → 按节目单轮播图片（每条可指定时长与转场）→ 双语字幕 → 音频与画面节拍同步 →
状态/自检/信息页随时可查。内容全部来自同一张 FAT32 卡的根目录；首次空参数 Flash 使用
`2/2/淡入/4` 默认值，现场设置保存到 W25Q64 后重启恢复。串口只做单向数据显示，不接收命令，
也不与其它外设联动。当前发布版只从 HDMI_B 输出。

## 2. 卡根目录要放什么

| 文件 | 作用 | 必需 |
|---|---|---|
| `PLAYLIST.TXT` | 节目单（每行一条节目） | 产品演示必备；没有时只按目录顺序播放 |
| `*.bmp` | 24 位未压缩 BMP 图片，源分辨率见下表 | 至少 1 张 |
| `*.wav` | 48kHz / 16 位 / 立体声 PCM | 选填 |

**图片源尺寸可按需要混用**（固件自适应，转场与字幕不区分尺寸）：

| 源分辨率 | 固件通路 |
|---|---|
| 640×480 | 原样透传 |
| 1280×960 | **2×2 均值**降采样到 640×480（比"每 2 个取 1"平滑，无摩尔纹） |
| 1024×768 | 每 8 个像素/行取 5（8:5） |
| 320×240 / 320×180 | 放大到 640×480（老卡兼容） |

**首图建议放 640×480**：上电到首帧的时间受实际卡速影响。打包器优先复制 640×480 图，避免以 3.7MB 大图开场。非 FAT32 卡不再进入旧版原始扇区扫描。

## 3. 节目单怎么写

每行一条，四个字段用逗号分隔（字段前导空格会被忽略）：

```
序号, 显示秒数, 转场, 字幕文本（可空）
```

- **序号**：扫描到的第几张图（1 起，当前最多 4 张）。0、多位数字、5~9 视为越界，
  按第 7 张提交并计一次错误；播放器遇到不存在的图片会保留当前完整画面。
- **条数上限 16 条**（每行一条；第 17 行起计入自检页的"节目单错误"计数并忽略）。
  无 WAV 时按 8 秒一条算，16 条约 2 分钟一循环；秒数留空就是 8 秒。
- **显示秒数**：无 WAV 时使用该秒数（`0` 用默认周期）；有 WAV 且自动或演示播放时以音频节拍为准。
- **转场**：`淡入` / `左揭示` / `右揭示` / `菱形溶解`（也接受数字 0~3）；写别的会回落淡入并计一次错误。
- **字幕**：该行第 3 个逗号之后的全部内容（含逗号），每种语言最多 **39 字**，超出自动截断；
  留空则该条不显示词条。用 `|` 分隔两种语言：`|` 前显示在上行，`|` 后显示在下行；
  ASCII 小写会自动转成大写（字库只有大写）。中文和英文各占屏幕底部一整行，
  固定显示且没有整片底色，照片可透过字间空白。
- `#` 开头的行是注释，空行忽略；行尾没写换行也会被正确收尾。

示例（`assets/scale_demo/PLAYLIST.TXT` 就是这份）：

```
# LGT 音画同频数字标牌 · 节目单
1, 8, 淡入, 欢迎参观 LGT 音画同频数字标牌|WELCOME TO LGT
2, 5, 左揭示, 四路图片常驻缓存 切换无需重新读卡|FOUR IMAGES READY IN MEMORY
3, 0, 菱形溶解, 音频节拍驱动画面切换 音画同频|PHOTO CHANGES FOLLOW THE MUSIC
4, 10, 右揭示, 交互 KEY1 切换布局 SW1 查看设备信息|KEY1 LAYOUT SW1 DEVICE STATUS
```

节目单最多 **16 条**（第 17 行起计错误并忽略）。示例文件在
`assets/scale_demo/PLAYLIST.TXT`。请先运行 `scripts/package_content.py`，再按清单顺序复制到唯一的 TF 卡。

## 4. 改内容前先自检

```bash
python scripts/check_playlist_font.py        # 字幕用字是否都在 16x16 字库里（缺字上屏是空框）
python scripts/check_tf_image.py E:\01_xxx.bmp   # 图片是否是固件认识的 BMP（逐张查）
```

字库是固定的 256 槽（当前用 183）。如果新写的字幕缺字，把缺的字加到
`scripts/gen_osd_chinese_font.py` 的 `CHARS` 里重跑该脚本。它会同时重新生成
16×16 字模、字形索引表和静态文案 ROM，并自带"文案用字齐全"断言；然后重新编译比特流。
**这是唯一需要动固件的常见原因。**

## 5. 上电之后会发生什么

1. 未插 TF 卡时保持中央大号 LGT 封面与“插卡即播”；插卡后先显示封面。
2. **开机自检页**：卡已挂载而首图还没出来时，显示 TF 卡挂载 / 图片扫描 / SDRAM 读写环回 / 音频通路 / HDMI 显示锁定 / 存储自检 / 节目单解析，
   逐项绿点=通过、红点=失败，失败也照常进播放（红点只是提示）。
   首图出来之前可用 **KEY2（上一页）/ KEY4（下一页）** 在自检页、播放证明 LOG 页、
   无内容引导页之间翻页；卡已挂载但没有图片时 2 秒后自动落到引导页。
3. 第一张图（首图）→ 按节目单轮播；有 WAV 时自动/演示切图跟随音频节拍，无 WAV 时按节目单秒数。
4. 四条示例节目都有上下两行中英文字幕；S5 关闭，S6/S7/S8 分别显示 50/75/100% 清晰度。右上角旧角标和照片中部黑色提示条已移除。
5. 只有 SW3 拨下的手动模式才计屏保时间：连续 **1 分钟**没有按键、也没有换卡，画面回到亮色品牌屏保。SW3 拨上立即退出并清零；再拨下从零计时。任意按键或换卡也会恢复。

要优先演示首轮切图速度，可使用已校验的 `build/card_fast_20261018`。它把两张高分辨率示例图预缩到 640×480，四张图总量约 3.69 MB；原 `assets/scale_demo` 为约 7.89 MB，保留作板上缩放效果展示。两种卡内容都需按各自 `MANIFEST.TXT` 顺序复制到 FAT32 根目录。

RESET/PROGRAM 会重新配置 FPGA，但 TF 卡仍有电。复位后串口应从
`LOAD_PHASE=SD_INIT` 进入 `LOAD_PHASE=READY`，`TF_CARD` 变为 `READY`，
`IMAGE` 回到有效图片编号；不能只把自检页出现当作恢复成功。

## 6. 板上的操作

| 控制 | 作用 |
|---|---|
| KEY1 短按 | 单图 ↔ 四宫格拼贴墙；缩略图浏览中：选中焦点图 |
| KEY1 长按 | 下一首背景音乐；缩略图浏览中：退出浏览 |
| KEY2 短按 | 下一张图；编辑档中加一档；首图前：上一页 |
| KEY3 短按 | 切换编辑档（亮度/对比度/特效/音效） |
| KEY3 长按 | 进入/退出缩略图浏览 |
| KEY4 短按 | 上一张图；编辑档中减一档；首图前：下一页 |
| SW1 拨上 | 整屏产品信息页（评委模式） |
| SW2 拨上 | 常显四行状态栏与自检行（拨下默认干净） |
| SW3 拨上 | 自动轮播开关 |
| SW4 拨上 | 演示模式（临时轮播，不保存临时参数） |
| S9~S12 | 选择并持续使用一种转场；等待保存后断电也会恢复 |
| 矩阵键 S1~S16 | 直接选图 / 选转场 / 选字幕档 |

单卡产品版将亮度、对比度、转场和音量保存在 W25Q64 的 `0x7FE000` 配置槽；停止调节约半秒后写入，确认写完再断电。播放事件日志仍写在 W25Q64 的 `0x700000` 起 16 个 4KB 槽位，
与 FPGA 配置 Flash 是两颗不同器件。

## 7. 屏上播放记录与串口健康状态（只读）

播放事件记录在屏幕上查看：开机自检页窗口内用 KEY2/KEY4 翻到“播放记录”页，
显示最近 7 条中文事件（时间 / 事件 / 图片），更早的记录留在 W25Q64 环形日志里。

串口只输出健康状态。板上有 115200 波特率的单向报文（`uart_tx`），**固件不接收任何串口命令**。
运行中每约一秒输出一行 190 字节可读状态：

```
UPTIME=01:02:03 IMAGE=2/4 AUTO_MODE=ON TF_CARD=READY WAV_AUDIO=READY BRIGHTNESS_LEVEL=2 CONTRAST_LEVEL=2 VOLUME_LEVEL=4 TRANSITION=FADE PLAYLIST_ERRORS=0 LOAD_PHASE=READY HEALTH=0
```

等级字段为板上 0–4 档；`IMAGE` 是当前张数/扫描总数；`LOAD_PHASE` 直接给出读取阶段名称；`HEALTH=0` 表示未记录到健康错误。屏幕顶部“分辨率”显示当前 BMP 的真实源尺寸，而 HDMI 输出固定为 640×480@60。

只读监视并留证：

```bash
python scripts/uart_status_monitor.py COM5 --save demo_capture.txt
```

抓到的就是每秒状态行；`UPTIME` 是“上电以来”的相对时间，不是墙钟时间，需要绝对时间时
在开始采集时记录实际时间作为人工锚点。串口只发不收，RXD 不接入 FPGA 逻辑。

## 8. 已知限制

- 单卡产品版保存亮度/对比度/转场/音量，但使用一个 4KB 参数槽。擦写中断电时校验可能失败并回默认值；断电演示须等待一次正常保存完成。
- 串口只从 TXD 单向输出，RXD 不接入 FPGA；不与按键、LED、Flash 或其它外设联动。
  本设计不使用数码管和蜂鸣器。
- 画面特效档保留 6 档（关闭 / 灰度 / 反色 / 棕褐 / 左右镜像 / 边缘）；
  亮度/对比度、5 段均衡和转场不受影响。
- 为面积，棕褐档用移位近似、边缘档用单像素差分（旧版 3×3 Sobel 的行缓存已下线）；
  6 个档位仍在，观感保留。
- 1024×768 走 8:5 相位抽取；面积加权模块及单测保留，但单卡 bit 未例化，不能以该画质宣称上板结果。
- 音频音效为 5 段一阶分频图形均衡（100Hz / 300Hz / 1kHz / 8kHz 分界，5 段分别
  0.5x/1x/2x），当前提供 4 档预设（原声/低音/明亮/低音+明亮），可通过 KEY3 编辑链现场切换。
  更精确的 IIR 版本 `audio_eq.v` 已实现并通过 ±1dB 频响测试，但集成后 mslice 超限（5,165 > 4,900），
  因此未例化；逐段 ±3dB 的独立按键调节也随 IIR 版本一起留到下一轮。
- 无 WAV 时当前版静音，不提供测试音；不使用 `TEXT.TXT` 或非 FAT32 原始扇区回退。
- 单卡参数保存版的 bit、面积与时序数据以本次完整构建输出为准。旧 `signage_subtitles_seed13.bit` 不支持参数掉电恢复。

## 9. 编译/刷板（维护者）

```powershell
powershell -File scripts/td_build.ps1                       # 面积优先（发布策略），出比特流
powershell -File scripts/td_build.ps1 -SynOnly              # 只跑综合，快速看面积
powershell -File scripts/td_build.ps1 -Seed 3 -ReuseSyn     # 复用综合，换布局种子搜时序
powershell -File sim/run.ps1 tb_wav_load                    # 单个仿真
```

比特流在 `<输出目录>/td_project/…_Runs/phy_1/*.bit`，本仓库把验证过的版本存在 `_flash_work/`。
新增 RTL 文件要手工登记到 `td_project/*.al` 的源文件列表，否则 TD 报 module 未定义。

下载到板子：把要烧的那份复制成 `_flash_work/top.bit`，再用 TD 命令行跑同目录的
`program.tcl`（内容 `download -bit top.bit -mode program_spi -spd 6 -cable 0`，即烧进
板载配置 Flash）；`verify.tcl` 是同一份的读回校验。

上一版已生成的 bit 为 `_flash_work/signage_subtitles_seed13.bit`，MD5
`637A98D32CC40AB7085F0F7D66F2F5A0`；它不含本轮单卡参数保存与一次性转场预览。
正式下载前从[功能与验收总表](FUNCTIONS-AND-VALIDATION.md)确认新的候选文件、MD5 和实卡状态。
